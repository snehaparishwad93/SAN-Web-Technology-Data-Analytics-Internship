# SAN Web Technology – Data Analytics Internship

## About the Internship
This repository contains the tasks and projects I completed during my Data Analytics Internship at SAN Web Technology.

The internship helped me practice data cleaning, data analysis, SQL queries, data visualization, and reporting.

## Internship Tasks

### Level 1 – Fundamentals
- **Task 1: Excel Data Cleaning and Analysis** – Cleaned and organized data, created pivot tables, and prepared a summary report.
- **Task 2: SQL Foundations** – Practiced SQL queries, joins, aggregations, and multi-table analysis using sample datasets.
- **Task 3: Exploratory Data Analysis (EDA)** – Internship task notes and supporting materials.

### Level 2 – Intermediate Analysis
- **Task 1:** Task notes and supporting materials.
- **Task 2:** Advanced SQL queries, analysis notes, and screenshots.
- **Task 3:** Executive summary and supporting screenshots.

### Level 3 – Advanced Tasks
- **Task 1:** Project notes and supporting materials.
- **Task 2:** Task notes and recording excluded from this repository.
- **Task 3:** Dataset and task notes.
